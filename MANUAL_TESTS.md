# Manual tests

Run on a real Windows 10/11 PC with a microphone and speakers/headphones. Target: about 20 minutes.
Record pass/fail per step and report back any failure with the line from
`%APPDATA%\Wisp\logs\wisp.log` that shows the error.

Setup: install with `WispSetup.exe` (or run `.venv\Scripts\python -m wisp`), then add your API key in
Settings → General.

Steps are added per phase below.
