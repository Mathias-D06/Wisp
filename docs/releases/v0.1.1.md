A small update to Wisp 0.1.0: the uninstaller is now easy to find.

## What's new

- **Start menu → Uninstall Wisp:** a shortcut next to Wisp's own.
- **Settings → General → Uninstall Wisp…:** asks first, then closes Wisp and starts the uninstaller. You won't see "Wisp is currently running", because a small helper waits for Wisp to close before starting it. The button only appears in an installed copy.

The uninstaller itself is unchanged. It asks before removing anything, removes the program, its shortcuts and the start-at-sign-in entry, and then asks whether to delete your Wisp data too (the default is to keep it). It is still also under Windows Settings → Apps → Installed apps → Wisp.

## Install or update

Download **WispSetup-0.1.1.exe** below and run it. It updates an existing installation in place and keeps your settings and data. It installs for your user only, with no administrator rights needed. The installer isn't code-signed, so Windows SmartScreen will warn you; choose **More info → Run anyway** if you trust this release.

New to Wisp? See the [0.1.0 release notes](https://github.com/Mathias-D06/Wisp/releases/tag/v0.1.0) and the [user guide](https://github.com/Mathias-D06/Wisp/blob/main/docs/USER_GUIDE.md).

## How it was checked

- Built and tested by CI on GitHub (`windows-latest`): lint, the automated tests, and the 15-check self-check of the built app.
- New tests cover finding the uninstaller only in an installed copy, the helper waiting for Wisp to close, and the Settings button and its confirmation. They never start a real uninstaller. The built helper was also checked on the author's PC with a stand-in uninstaller.
- The end-to-end check on an installed copy is manual test MT-125 in `MANUAL_TESTS.md`.
