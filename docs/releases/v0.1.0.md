The first release of Wisp, a voice assistant for Windows 10 and 11 built on Google's Gemini
Live API.

## What's in it

- **Voice:** push-to-talk or always listening, barge-in, typed questions, and 48 tools in 16 skill
  groups for opening apps, managing windows, reading and clicking the screen, and controlling the PC.
- **The Island:** one surface at the top of the screen. It has tabs for Today, Calendar (Google
  Calendar), Files & Share (a shelf, search and a link to your phone), Screen, clipboard history and
  system controls, and hides itself when idle.
- **Screen Assist** (Ctrl+Alt+Space) answers questions about the window in front, and **Watch mode**
  comments when something changes. A blocklist keeps password managers, banking and private windows
  out.
- **Discreet mode** (Ctrl+Alt+D) gives a quiet look with text-only answers.
- Dictation, Circle to Ask, to-dos, routines, memory, a loadout, stats and a safety layer.

## Install

1. Download **WispSetup-0.1.0.exe** below and run it. It installs for your user only; no administrator
   rights needed.
2. The installer isn't code-signed, so Windows SmartScreen will warn you. Choose **More info → Run
   anyway** if you trust this release.
3. Add a Gemini API key in **Settings → General**. Create one at
   <https://aistudio.google.com/api-keys>. In the UK, EEA and Switzerland Google requires a key from
   a billing-enabled project.

The [user guide](https://github.com/Mathias-D06/Wisp/blob/main/docs/USER_GUIDE.md) covers everything
else.

## How it was checked

- Built and tested by CI on GitHub (`windows-latest`): lint, 677 automated tests, and a
  self-check of the built app with 15 checks. One check runs Screen Assist end to end with a local
  stand-in for Gemini.
- Run from source and as a build on the author's PC.
- The hands-on checks in `MANUAL_TESTS.md` (real speech, accounts, a phone, a second monitor) are
  still to be done for this release. Please report problems as issues, with the matching lines from
  `%APPDATA%\Wisp\logs\wisp.log` (they never contain your API key).

## Known limitations

- A few system toggles (Night Light, dark mode, default output device) rely on undocumented Windows
  behaviour. Each is isolated and fails gracefully.
- When Gemini is overloaded ("503, high demand"), Wisp retries for about 20 s, then says so. You can
  name a fallback model in Settings → General.
- Free-tier Gemini keys let Google use what you send to improve its products.
